# MMTR 记忆观察台

当前默认优先 MMTR，腾讯记忆暂不使用。配置加载、记忆管理器、独立认知核心和部署入口共用这一策略；旧私有配置中的腾讯开关不会覆盖它。Node 需要 >=22.13。MMTR 启动失败会明确报错，不自动切换腾讯。旧腾讯数据不删除，也不自动迁移。

## 云端更新与打开

在服务器项目目录执行：

```bash
sudo bash auto-update.sh run
sudo bash auto-start.sh token
```

打开 `http://服务器IP:8010/memory.html`，填入第二条命令输出的访问密钥。也可从聊天页面顶部的“记忆观察台”进入。UI_PORT 修改后使用对应端口；中控 HTTP 入口同样提供 `/memory.html`。首次安装自动拉起请先参照 [部署说明](cloud-deployment.md)。

密钥依次读取环境变量 `MMTR_WEB_TOKEN`、配置 `mmtr.web_token`、认知核心 API 密钥；都没有时自动生成到 `data/deploy/mmtr-web.token`。浏览器只在当前标签页会话中保存密钥，接口始终需要认证。请通过已有 HTTPS 反向代理访问公网部署，密钥能够读取页面展示的对话内容。

## 页面展示什么

- 当前对话：实际用户输入、会话时间线、历史回合与自动刷新。
- 记忆关联：本轮真正召回的句子、实体与主题、召回来源、图连接和可用的 fact/gist/affect 强度；不存在的通道显示横线。
- 思维核心引用：实际目标、规则判断、可见的简短决策理由，以及哪些内容提供给了模型。点击节点查看原句与来源，切换“词语 / 句子”查看关联。

关联词来自真实元数据和文本共现。连线表达检索或上下文引用关系，不代表模型注意力权重。这里展示可审查的认知状态与简短结果说明，不展示模型内部思考过程，也不虚构情绪和实体。自动刷新只读取已有记录，不再次检索，不增加记忆回血或改变排序。

记录从升级后的新对话开始产生，旧对话不会自动补出关联图。需启用认知核心；核心关闭、接口断开、密钥错误和无数据都有对应状态。记录保存在认知核心 SQLite 中，最多保留最近 120 条且不超过 7 天；页面每个会话最多显示 40 条。它是观察记录，不替代 MMTR 的长期记忆库。

## 验证范围

Python 全套 84 项、MMTR Node 24 项测试通过。观察台覆盖后端优先策略、私有密钥、认证、会话隔离、重启后读取、保留上限、代理转发、观察不回血及观察失败不影响对话。

浏览器使用 Playwright 驱动本机 Edge，检查 1505×1045 桌面及 390×844、320×740 手机视口；验证连接、节点详情、词句切换、历史、会话切换、暂停与刷新、实时新记录、错误密钥、断开和文本注入防护。测试使用真实 MMTR 与认知核心，模型回复为测试桩。尚未在真实云主机、QQ/ESP 或生产模型上做端到端验证。
