# DSH 与可视化知识库

## DSH 接入

控制器通过 DeepSeek Harness 官方 headless CLI 运行单次任务，不启动常驻 DSH 服务。用户提出任务，或每日随机思考认为有合适任务时，控制器只会创建一条带一次性确认码的待办请求，并在 QQ 私聊展示具体任务与理由。只有主人在同一私聊回复“同意 DSH-XXXXXX”后才会运行；“拒绝 DSH-XXXXXX”会取消。确认码十分钟有效、只能使用一次，新的请求会使旧请求失效。安装 DSH CLI、配置 API、插件操作、权限调整、普通任务和 DSH 自我修改都分别请求同意。

运行的进程使用 OII 服务账号、`dsh.profile`（默认 `headless`）及 `dsh.workspace`（默认项目目录）配置的权限。任务无法自动越过服务账号的操作系统权限。每次运行有超时限制；服务重启后，不会自动重试尚未结束的 DSH 任务。

首次在 QQ 对主人说“安装 DSH 运行时”，确认安装请求后才会通过 npm 安装官方 `@deepseek-ai/dsh`。之后可提出单独的 DSH API 配置任务。API 密钥应在 DSH 自己的配置中维护；控制器不会把 YAML 里的聊天密钥注入 DSH 子进程。

每日主动思考只在配置的随机时间窗口内尝试一次，默认上海时间 09:00–22:00；会从近期对话和已学的 B 站资料取线索。主动思考若建议 DSH 操作，仍必须经过同一套 QQ 单次确认。

## 知识花园

在中控页面顶部选择“知识花园”，或直接打开 `/knowledge.html`。使用记忆观察台的只读访问密钥连接；密钥只存于当前浏览器会话。知识页展示：

- **B 站梗卡片**：梗词、解释、适用语境、字幕中的原句证据，以及视频和时间点链接。
- **视频学习笔记**：已整理的主题摘要、少量字幕摘录和原视频链接。
- **图片与表情包**：从 QQ 私聊图片中保存的本地图片、识图文字、意图、语境和图像表达情绪。页面不会把图像情绪当成发送者真实情绪。
- **知识统计、过滤与搜索**：按梗、视频笔记、图片筛选，并搜索已展示的文本。

页面读取现有 `data/knowledge/knowledge.db`，不建立第二份知识库；知识按 QQ 私聊隔离。接口仅接受同一观察密钥，图片端点也会检查所属范围。页面只读取最近 200 个来源和最近 100 张图片的索引；每个来源最多带 8 段摘录。图片保持在服务器本机，使用时通过带身份验证的接口读取，不交给第三方图床。知识页在 UI 静态服务与中控 HTTP API 上都可访问。

## 云端更新

代码推送后，在服务器运行：

```bash
cd /home/oii
sudo bash auto-update.sh run
```

服务重启后，从中控顶部打开知识花园并用以下命令获取访问密钥：

```bash
sudo bash auto-start.sh token
```

知识为空时，先确认 B 站学习已登录、学习服务开启，并等待下一次梗整理；QQ 图片需经过启用的视觉识别流程后才会进入图片库。
