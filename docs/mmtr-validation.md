# MMTR 实现与可行性验证

验证日期：2026-10-29。测试在临时 SQLite 库中运行，没有连接 QQ、设备、生产模型或腾讯记忆服务。

## 环境与结果

- Windows，Node v24.22.1、Python 3.12。
- MMTR 无 `dependencies` 或 `devDependencies`，测试使用 `node:test` 与 `node:assert/strict`。
- `node --test mmtr/test/memory.test.mjs`：24 项通过。
- `python -m unittest discover -s tests -v`：53 项通过，包括新增 7 项 MMTR 联调，以及既有 21 项 Cognitive Core、15 项 Controller、4 项 QQ、6 项短信测试。
- `git diff --check`：通过。
- `node mmtr/examples/dumplings.mjs`：提起包饺子带回生日约定；推进 60 天后，具体聊天事实被清除，合拍的印象与安心的情绪仍然存在。

包的最低声明版本为 Node 22.13，依据该版本起内置 node:sqlite 无需实验启动参数；本次初始实测环境为 Node 24。

## 验证覆盖

| 行为 | 验证方法 |
| --- | --- |
| fact/gist/affect 独立遗忘 | 可控时钟检查各半衰期与长期地板，巩固后检查 fact 内容清空 |
| 事实消失仍保留情绪 | 60 天后查询不含原始时间细节，affect 内容和强度仍保留 |
| 向量仅作为入口 | 检查 embed 输入不含 fact 原文，用正交向量证明无查询重合的生日约定经 entity 边回来 |
| 四类边与多跳 | 检查 entity/temporal/calendar/theme，分别验证 0/1/2 跳可达性 |
| 日历唤醒 | 无向量相关性也能唤醒；检查跨年、闰日，巩固可修复不合法旧锚点 |
| 六维关系 | 会话中不更新，结束后一次更新，单场上限、饱和减速、重复 sleep 无效 |
| 关系回归 | 张力 7 天、其他维度 120 天；重复巩固不重复衰减 |
| 前瞻记忆 | 越近越清晰，提醒绕过查询相关性，数据库触发器锁定原文，任何年龄不压缩 |
| kept/broken | 恰好在宽限期边界不失约，超出后只扣一次，兑现只奖一次，过期 keep 不能逃避失约 |
| 常驻区 | 显式身份事实跨任意年龄保留，拒绝明显事件，所有 core 完整占用预算 |
| 防自增强 | 回血增益递减且封顶，下一轮降权，重要性不变，未装入上下文的不回血 |
| quiet/full 与多样性 | 不附加评分等内部标签；MMR 与相同文字去重；预算不截断承诺，遗漏项有诊断 |
| 会话间隔 | 等于间隔不结束，超过间隔先 sleep；摘要及未完话题入普通记忆；重启不误开新场 |
| 数据隔离和一致性 | scope 隔离，外部 ID 去重，输入校验失败回滚，SQL 样式文本按数据保存 |
| 跨语言与中控 | 真实 Python→Node→SQLite 调用，多线程串行请求，重启读取，工具观察白名单，quiet 不丢失 |
| 故障与资源 | 缺 Node 明确报错，桥接错误后重启恢复，认知接口传播 degraded 状态，旧 SQLite 连接退出时关闭 |

## 规模测量

命令：`node mmtr/examples/benchmark.mjs 1000`。
这是内存 SQLite、真实默认特征哈希、写事务和检索回血的测量，不含远程 embedding、网络和磁盘延迟。
输入有共同人物、主题与近邻时间，刻意制造密集联想场景。

| 项目 | 本机结果 |
| --- | ---: |
| 记忆数 | 1000 |
| 边数 | 42152 |
| 总写入时间 | 1007 ms |
| 10 次检索中位耗时 | 129 ms |
| 最慢一次检索 | 150 ms |

每条新记忆每类最多新增 16 个邻居，因此边总量上界随记忆数线性增长，避免完整共享人物图的平方增长。
向量召回仍线性扫描；以上结果支持个人 agent 的小规模使用，不代表高并发、百万级数据或真实语义模型的吞吐。

## 已实现的边界

MMTR 实现记忆的生命周期和关联结构；自然语言的可靠语义提取需要宿主 agent 提供结构化字段。
默认只有保守文本概括与离线词法向量，情绪留空；语义 embedding、实体、主题、关系变更、承诺和日期提取可由宿主注入。
不声称已有零依赖的通用自然语言情绪理解模型。

提醒在 recall 时进入上下文；巩固由调用方触发，没有内置后台通知或主动消息发送。
日历采用 UTC，字符预算不是 token 预算；承诺放不下时保留完整原文并返回遗漏诊断，core 放不下则明确报错。
单库是 MMTR 模块的数据边界；原中控保留其既有状态库、身份与凭据库。
未执行生产部署、真实设备和外部服务联测，也没有迁移或改写用户已有记忆。

启用、语义提取接入点与回退步骤见 [接入指南](mmtr-integration.md)。
